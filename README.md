# OmniKit

开发者桌面工具箱 —— 一批常用小工具装进一个应用，全程本地处理，数据不出设备。

基于 Tauri 2 + React 19 构建，安装包小、内存占用低，支持 Windows 与 macOS（Apple Silicon）。

## 下载安装

前往 [Releases](https://github.com/Rosons/omnikit/releases/latest) 下载对应平台安装包：

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `OmniKit_x.y.z_x64-setup.exe` |
| macOS Apple Silicon | `OmniKit_x.y.z_aarch64.dmg` |

安装包未做代码签名，Windows 首次运行若弹出 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

应用内置自动更新：设置页可手动检查，新版本可直接在应用内下载安装；也可开启「启动时检查更新」自动提醒。

## 功能一览

**文件工具**

- **文件保险箱** —— 文件打包加密为 `.box`（Argon2 派生密钥 + AES-256-GCM），凭密码还原
- **文件搜索** —— 全盘文件名索引，秒级搜索，支持扩展名筛选与内容预览
- **磁盘分析** —— 重复文件查找与目录占用统计
- **文件管理** —— 保险箱加密/解密历史记录

**开发工具**

- **数据工具箱** —— JSON 格式化、编解码、哈希、JWT 解析、SQL 格式化、URL 解析、进制转换、Base64、时间戳等 11 项小功能
- **HTTP 测试** —— 本地发起请求，支持 cURL 导入、请求历史、环境变量、超时设置
- **MCP 测试** —— 连接 MCP 服务器调试工具调用，支持 stdio / Streamable HTTP / HTTP+SSE 三种传输
- **文本对比** —— 两段文本或文件逐行差异
- **正则测试** —— 实时匹配高亮与分组解析
- **Cron 表达式** —— 定时表达式解析与下次执行时间预览
- **日志查看** —— 实时跟踪日志文件，按级别着色与关键字过滤

**系统工具**

- **端口占用** —— 查看监听端口并结束占用进程
- **进程管理** —— 全部进程、资源占用与结束
- **系统监控** —— CPU、内存与磁盘实时状态

**常用工具**

- **剪贴板** —— 复制历史（文本与图片预览）一键回贴，可选 AES-256-GCM 加密落盘，密钥存系统凭据库
- **二维码** —— 生成与识别，全程本机处理
- **密码生成** —— 随机强密码批量生成
- **颜色工具** —— HEX 与 RGB、HSL 互转

**应用级能力**

- `Ctrl+K` 命令面板，常用工具可收藏置顶
- 全局快捷键 `Alt+Q` 随时唤起/隐藏窗口
- 关闭最小化到托盘、开机自启、深浅色主题跟随系统
- 设置一键导出/导入，跨设备迁移配置
- 运行日志本地落盘（512KB 轮转），页面异常可追溯

## 隐私

- 所有工具在本地运行，请求数据、剪贴板内容、文件内容均不经过任何服务器
- 「检查更新」只查询 GitHub 上的最新版本号，不上传任何数据；可在设置中关闭
- 剪贴板历史若开启落盘，使用系统凭据库保管的密钥加密后存本机

## 从源码构建

依赖：Node.js 20+、Rust 1.77+、Tauri 2 系统依赖（Windows 需 WebView2，macOS 需 Xcode Command Line Tools）。

```bash
npm install
npm run build        # 前端构建 + 全角标点检查
npm test             # 前端单元测试
npm run tauri dev    # 开发调试
npm run tauri build  # 打包
```
